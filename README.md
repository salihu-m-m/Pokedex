# Pokedex (Clone)

A lightweight Pokedex clone built with TypeScript.

This repository contains a small TypeScript project that implements a Pokedex-like application for viewing Pokémon data. The project is intended as a learning exercise and starter template for TypeScript-based single-page or command-line projects.

## About

This repository (Pokedex) is a clone of a Pokedex-style application implemented in TypeScript. It demonstrates how to structure a TypeScript project, compile sources, and run the resulting JavaScript.

## Features

- TypeScript-based codebase
- Build and run scripts
- Test runner configuration (Vitest)

## Tech stack

- TypeScript (100% of repository)
- Node.js
- Vitest (for testing)

## Requirements

- Node.js 18+ (LTS recommended)
- npm (or pnpm/yarn, if you prefer — commands shown use npm)

## Installation

1. Clone the repository:

   git clone https://github.com/salihu-m-m/Pokedex.git
   cd Pokedex

2. Install dependencies:

   npm install

3. Build the project:

   npm run build
   
## Project structure

A typical layout for a TypeScript project is shown below. Adjust these notes to match the actual repo layout if it differs.

- src/            — TypeScript source files
- dist/           — Compiled JavaScript output (generated by the build step)
- package.json    — npm scripts and project metadata
- tsconfig.json   — TypeScript compiler configuration
- README.md       — this file

If your code places the main entry file at a different path, update `package.json` and scripts accordingly.

## Testing

Run tests with:

   npm run test

Vitest is included as a dev dependency in package.json. Add test files under a `test/` or `src/` directory and use the `.test.ts` or `.spec.ts` naming convention.
